# SEO Methodology Baseline v1.0 — FROZEN ROLLBACK STATE

Status: FROZEN
Baseline date: 2026-09-14

## v1.0 workflow
`QUERY -> SERP -> PAGE OWNERSHIP -> FOUR STARS -> VOICE/CONVERSION -> QA -> SHIP -> MEASURE`

## v1.0 title approach
Default: `Primary Keyword + Buyer Intent | Brand`. The title is primarily an alignment signal; secondary title space may carry buyer intent, service/local framing or supporting commercial language.

## v1.0 Four Stars role
Four Stars validates the chosen query across title, H1, meta, first substantive sentence and H2s. It does not choose the query and does not guarantee ranking.

## v1.0 protections
- one primary intent, one URL owner
- protect winners and active experiments
- evidence outranks aesthetic preference
- do not stuff exact-match variants merely to raise a score
- isolate changes when attribution matters

## Rollback
Before a v1.1 established-page experiment, record the exact live pre-change title/meta and relevant SEO spine plus Four Stars/GSC baseline. If rollback criteria fire, restore that exact state.
