# SEO Operating System v1.1

Status: ACTIVE DEFAULT FOR NEW WORK
Effective: 2026-09-14

## Objective
Own the correct query, earn the highest practical ranking, win a disproportionate share of qualified SERP clicks, and convert that traffic into the business outcome.

## Workflow
`QUERY -> SERP -> PAGE OWNERSHIP -> FOUR STARS -> SERP CTR -> PAGE EXPERIENCE -> AUTHORITY/ENTITY -> QA -> SHIP -> MEASURE`

## Core rules
- define primary query, secondary cluster, search intent, searcher's real goal/problem, and business value before editing
- inspect the actual SERP before deciding structure or CTR copy
- one primary intent should have one clear URL owner
- Four Stars validates title, H1, meta, first substantive sentence and H2 alignment; it does not choose strategy
- strong Four Stars with weak rank means investigate authority/entity/intent/selection before adding more keyword copy
- existing winners and active experiments are protected

## SERP CTR title rule
The title has two jobs: machine relevance and human persuasion.

Default:
`TARGET KEYWORD | SEARCHER BENEFIT OR GOAL | BRAND`

The middle phrase should communicate a real outcome, solved problem, convenience, supportable speed/price certainty, proof, or differentiator. Avoid generic filler and unsupported claims.

## Existing-page exception
Do not rewrite an existing title solely for template compliance. GSC/SERP evidence and protected state outrank the formula.

## H1 / hero / meta
- H1 prioritizes query/topic clarity
- hero/subhead explains the outcome and value
- meta reinforces the click decision rather than repeating the title
- the page must substantiate the SERP promise

## Authority / entity / GEO
If alignment is strong but ranking is weak, investigate links/authority, brand/entity corroboration, GBP/local signals where eligible, page age, business-type SERP fit, citations, schema/entity clarity and competitive strength.

## Measurement
Track impressions, position, CTR, qualified leads/conversions and ranking URL.
- strong position + weak CTR = SERP/title opportunity
- weak position = ranking/relevance/authority/ownership problem first
- strong rank + CTR + weak leads = page/offer problem
- A-grade Four Stars + weak rank = non-alignment bottleneck investigation

## Experiment rule
Before changing an established live title/meta, record exact current title/meta, H1/first sentence if relevant, Four Stars baseline, GSC baseline, hypothesis, intervention, observation window, success criteria and rollback criteria.

## Conflict hierarchy
1. factual/legal honesty
2. target query + intent
3. SERP/GSC evidence
4. page ownership / regression protection
5. Four Stars SEO spine
6. SERP CTR opportunity
7. voice/brand governance
8. conversion refinement
9. stylistic preference

## Success definition
`QUALIFIED SEARCH DEMAND x SEARCH VISIBILITY x SERP CTR x CONVERSION RATE`
