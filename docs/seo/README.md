# SEO Governance Entry Point

Active methodology: `SEO-OPERATING-SYSTEM-v1.1.md`
Frozen rollback baseline: `SEO-METHODOLOGY-BASELINE-v1.0.md`
Effective date: 2026-09-14

Any human or agent creating or materially modifying an indexable page must read both files first.

v1.1 is the default for NEW page work and NEW SEO experiments. Do not mass-rewrite existing titles. Existing winners and active experiments keep their current state until evidence supports a controlled intervention.

Default v1.1 title: `TARGET KEYWORD | SEARCHER BENEFIT OR GOAL | BRAND`

Every live-title experiment must record the exact pre-change state. If rollback criteria fire, restore that exact state.

Applies to Codex, Claude Code, ChatGPT-driven GitHub changes, human edits, and future coding agents. Repo-specific rules may be stricter but may not silently bypass these controls.
