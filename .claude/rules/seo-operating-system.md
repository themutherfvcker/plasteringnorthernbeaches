# SEO operating-system rule

Before SEO/page/metadata work, read:
- `docs/seo/README.md`
- `docs/seo/SEO-OPERATING-SYSTEM-v1.1.md`
- `docs/seo/SEO-METHODOLOGY-BASELINE-v1.0.md`
- `CLAUDE.md`
- `docs/BRIEF.md`

For NEW work and NEW experiments use:
`QUERY -> SERP -> PAGE OWNERSHIP -> FOUR STARS -> SERP CTR -> PAGE EXPERIENCE -> AUTHORITY/ENTITY -> QA -> SHIP -> MEASURE`

Default title formula:
`TARGET KEYWORD | SEARCHER BENEFIT OR GOAL | BRAND`

Do not mass-rewrite existing titles. Protected winners and project-specific factual/GBP/NAP constraints remain protected. Every established-page title experiment needs an exact pre-change snapshot and rollback plan.
